# 🌱 MOSS Quest Planner

> 매일의 퀘스트를 깨며 성장의 숲을 가꿔나가는 준비 플래너

 바로 사용하기: https://mossmori.github.io/mossday/

## 소개
주 단위로 퀘스트를 생성하고, 달성률에 따라 다음 주 난이도가 자동 조절됩니다.

## 주요 기능
- 주간 퀘스트 자동 생성 — 로드맵 단계(SQLD → 포트폴리오 → AWS → 지원/면접)에 맞는 퀘스트가 요일별로 배분됨
- 성장 시스템 — 퀘스트 완료 시 XP 획득, 달성률에 따라 마스코트가 🌱→🌲로 성장 (Lv.1 새싹 이끼 ~ Lv.5 거대한 숲)
- 자동 난이도 조절 — 주간 달성률 80% 이상이면 다음 주 퀘스트 증가, 50% 미만이면 감소 + 격려 메시지
- 진도 추적 — 카테고리별(자격증·포트폴리오·이력서·면접) 도토리 수집 현황과 실제 날짜 기준 지연/정상 판정
- 기록 보존 — localStorage 기반으로 주차별 기록 저장, 지난 주 열람 가능

## 사용 기술

- HTML / CSS / JavaScript (단일 파일, 프레임워크 없음)
- localStorage 기반 상태 저장
- GitHub Pages 배포
